LIVE TV

### Notes
Fernsy is a player for the user’s own IPTV subscription (Xtream Codes API). It does not include, sell, link to or recommend any channels or content, and it has no in-app purchases. All content shown comes from the server the user signs in to.

The sign-in above points to our own demo server (source: `demo-server/` in https://github.com/obi12341/fernsy). It serves fictional channels, a program guide, movies and series; the videos are the Blender Foundation open movies “Big Buck Bunny” and “Sintel” (CC BY 3.0). Live channels, the program guide grid, movies with seeking and series episodes can all be tried with it.

Network: Most Xtream Codes servers only offer plain HTTP and redirect streams to changing hosts, so the app uses an App Transport Security exception (NSAllowsArbitraryLoads). Credentials are stored in the keychain; the app collects no data.

The screenshots use the same fictional demo content.

### Reply to Guideline 2.1 (Information Needed) – also paste into the Notes field

Hello App Review team,

thank you for the review. Please find the requested information below; the screen recording is attached.

1. Screen recording
Recorded on a Mac with Apple silicon running the latest macOS. It starts with launching Fernsy and shows signing in with the demo account, live TV (categories, channel list with now/next, playback, channel switching, technical info), the program guide grid, movies (catalog, details, playback with seeking), series (seasons, episode playback), favorites, settings and signing out. Fernsy has no account registration (accounts are created by the user’s IPTV provider, not in the app), no user-generated content and no paid content or in-app purchases. “Sign Out” in Settings removes the stored credentials from the Mac.

2. Purpose and target audience
Fernsy is a native macOS player for IPTV subscriptions that use the Xtream Codes API, a widely used standard among IPTV services. It is for people who already have such a subscription and want to watch it in a fast, native Mac app instead of a web browser or a generic media player. It solves the poor usability of existing options: Fernsy offers a full program guide grid, organized movie and series catalogs, resume playback, hardware-accelerated decoding and seamless recovery from network interruptions. Fernsy does not include, sell, link to or recommend any channels or content.

3. Setup and access
Launch Fernsy and sign in with:
   Server: https://fernsy-demo.mobilistics.workers.dev
   Username: demo
   Password: demo
This is our own demo server with fictional channels, program data, movies and series; the videos are the Blender Foundation open movies “Big Buck Bunny” and “Sintel” (CC BY 3.0).
- Live TV: select a channel and press Play (or double-click). The toolbar switch “List | Guide” shows the program guide grid. In the player, ↑/↓ switch channels, F toggles full screen, I shows technical information.
- Movies / Series: browse the catalog, open a title, press Play. Series show seasons and episodes; playback resumes where it was stopped.
- Favorites: the star button on channels, movies and series.
- Settings (Fernsy menu → Settings…): account information, “Show adult categories” (off by default) and Sign Out.

4. External services
- The IPTV provider chosen and configured by the user (Xtream Codes API over HTTP/HTTPS). It provides the catalog, program data and streams. For review this is our demo server, hosted on Cloudflare Workers, with media files hosted on GitHub.
- No other services: no authentication service, payment processor, analytics, advertising or AI service. Video decoding uses Apple’s VideoToolbox and the bundled FFmpeg libraries (LGPL), locally on the Mac.

5. Regional differences
Fernsy works the same in all regions. The user interface is available in English and German. The available content depends only on the user’s own provider.

6. Regulated industry / third-party material
Fernsy does not operate in a regulated industry and does not provide any third-party content; all content comes from the server the user signs in to. The demo content is fictional and was created by us; the demo videos are licensed under CC BY 3.0 by the Blender Foundation (https://peach.blender.org, https://durian.blender.org).
